# COMBO17

This folder contains the code and data required to reproduce the results presented in Section 7, *Application to Astronomical Data*, of the paper *A Fast Non-Reversible Sampler for Bayesian Mixture Models* by F. Ascolani, P. Manildo, and G. Zanella.

The folder includes the following files:

- `COMBO17.csv`: The COMBO17 dataset used in the analyses. A description of the data is provided in Section 7 of the paper.

- `model_fit.R`: Functions for fitting the Bayesian mixture model described in Section 7 using the different MCMC schemes considered in the paper.

- `simulations.R`: Code for the simulation study described in Section 7.

- `Figure_5.R`: Script to reproduce Figure 5. See Section 7 of the paper for details of the analysis and simulation setup.

- `Table_1.R`: Script to reproduce Table 1. See Section 7 of the paper for details of the analysis and simulation setup.
