# Reproducing the Figures

This folder contains the code required to reproduce Figures 1, 2, 3, 6, 7, 8, and 9 from the paper *A Fast Non-Reversible MCMC Scheme for Bayesian Mixture Models* by Ascolani, Manildo, and Zanella.

The folder includes the following files:

- `simulate_cluster_sizes.R`: Functions for simulating cluster sizes at each MCMC iteration under the different sampling schemes, models, and datasets considered in the paper.

- `plot_functions.R`: Utility functions used to generate the plots for the figures listed above.

- `Figure_1.R`: Script to reproduce Figure 1. See Section 1.3 of the paper for details of the simulation setup.

- `Figure_2.R`: Script to reproduce Figure 2. See Section 5.1 for details of the simulation setup.

- `Figure_3.R`: Script to reproduce Figure 3. See Section 5.2 for details of the simulation setup.

- `Figure_6.R`: Script to reproduce Figure 6. See Section F.2 for details of the simulation setup.

- `Figure_7.R`: Script to reproduce Figure 7. See Section J.1 for details of the simulation setup.

- `Figure_8.R`: Script to reproduce Figure 8. See Section J.2 for details of the simulation setup.

- `Figure_9.R`: Script to reproduce Figure 9. See Section J.3 for details of the simulation setup.
