# Figure 7

This folder contains the code required to reproduce Figure 7 from Section D of the Supplementary Material of the paper *A Fast Non-Reversible Sampler for Bayesian Mixture Models* by F. Ascolani, P. Manildo, and G. Zanella.

The folder includes the following files:

- `refreshment_rate_simulation.R`: Code for the simulation study described in Section D of the Supplementary Material.

- `Figure_7.R`: Script to reproduce Figure 7. See Section D of the Supplementary Material for details of the simulation setup.
