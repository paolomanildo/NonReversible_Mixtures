# Figure 4

This folder contains the code required to reproduce Figure 4 from Section 5.3 of the paper *A Fast Non-Reversible Sampler for Bayesian Mixture Models* by Ascolani et al. (2026)

The folder includes the following files:

- `simulation.R`: Code for the simulation study described in Section 5.3.

- `Figure_4.R`: Script to reproduce Figure 4. See Section 5.3 of the paper for details of the simulation setup.
