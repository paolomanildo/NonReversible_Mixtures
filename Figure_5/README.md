# Figure 5

This folder contains the code required to reproduce Figure 5 from Section E of the Supplementary Material of the paper *A Fast Non-Reversible Sampler for Bayesian Mixture Models* by Ascolani et al. (2026)

The folder includes the following files:

- `refreshment_rate_simulation.R`: Code for the simulation study described in Section E of the Supplementary Material.

- `Figure_7.R`: Script to reproduce Figure 5. See Section E of the Supplementary Material for details of the simulation setup.
